# ZibStore — Steam Matcher demo

Это отдельный пример интерфейса для полуавтоматического сопоставления товара Digiseller с Steam.

## Что делает

1. Загружает каталог Digiseller (если браузерный запрос доступен) или использует демо-товары.
2. Показывает товары без сохранённого Steam-сопоставления.
3. По кнопке «Найти Steam» отправляет название товара на backend.
4. Backend ищет до 10 кандидатов через публичный Steam Store Search API.
5. Ты выбираешь правильный `AppID` или `Package/SubID`.
6. Соответствие сохраняется локально в браузере.
7. Кнопка «Экспорт JSON» скачивает `steam-matches.json`.
8. Этот JSON можно использовать в основном сайте вместо ручного редактирования JS-карты.

## Что от пользователя

На постоянной основе требуется только подтверждать найденный Steam-вариант.

Для Premium / Deluxe / Bundle, если автоматический поиск не дал правильный объект, можно вручную указать ID и выбрать тип `AppID` или `Package/SubID`.

## Важно

Сохранение в `localStorage` — демонстрационный этап. Для постоянного командного хранилища нужно будет перенести `steam-matches.json` в репозиторий/хранилище проекта или сделать отдельный backend-редактор.
