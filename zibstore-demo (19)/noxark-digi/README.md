# ЗибСтор + Digiseller — демо интеграции виджета

Тёмный магазин ключей с честным сравнением цен и рабочими точками встраивания Digiseller.  
Слоган: **ЗибСтор — честное сравнение цен и удобство сортировки**.

## Что внутри

- Готовый HTML-сайт (без сборки, просто открывай `index.html`)
- Три карточки товаров с **двумя способами** покупки:
  1. Прямая ссылка на `oplata.info` с параметром `agent` (партнёрка)
  2. Место под официальный JS-виджет `digiseller-buy-standalone`
- Подробная инструкция прямо на странице (секция «Как вставлен виджет Digiseller»)

## Как сделать рабочим за 5 минут

1. Зарегистрируйся / войди в [my.digiseller.com](https://my.digiseller.com)
2. Найди свой **Agent ID** (партнёрский ID) — обычно в «Мои данные» или в ссылках товаров
3. Выбери товары (свои или чужие по партнёрке) и скопируй их **ID** (цифры)
4. Открой `index.html` в редакторе и замени:
   - `YOUR_AGENT_ID` → твой Agent ID
   - `DEMO_PRODUCT_1`, `DEMO_PRODUCT_2`, `DEMO_PRODUCT_3` → реальные ID товаров
5. (Опционально) Раскомментируй скрипт внизу страницы и укажи `seller_id` продавца — тогда появятся официальные кнопки Digiseller вместо простых ссылок.

## Два основных способа встраивания

### 1. Самый простой (рекомендую для старта)

```html
<a href="https://www.oplata.info/asp2/pay.asp?id_d=PRODUCT_ID&agent=YOUR_AGENT_ID&lang=ru-RU"
   target="_blank" rel="noopener">
  Купить
</a>
```

- Не нужны скрипты
- Параметр `agent` гарантирует, что комиссия придёт тебе
- Работает на любом сайте (даже на Tilda / WordPress / чистом HTML)

### 2. Официальный виджет

```html
<script src="//www.digiseller.ru/shop/digiseller-api.js.asp?seller_id=SELLER_ID"></script>

<div class="digiseller-buy-standalone"
     data-id="PRODUCT_ID"
     data-ai="YOUR_AGENT_ID"
     data-img="0"
     data-name="0"
     data-no-price="1"
     data-lang="ru-RU">
</div>
```

### 3. Полный магазин (весь каталог)

В кабинете Digiseller: **Магазин → HTML-код** → скопировать код → вставить на страницу → указать URL этой страницы в настройках магазина.

## Про комиссию (напоминание)

- 1,5% Digiseller берёт **с продавца**
- Твоя партнёрская % (которую выставил продавец) идёт **тебе отдельно**
- Поэтому `agent=` / `data-ai=` — критично важно
