ЗибСтор — тест Steam цен

В архиве:
- index.html — тестовый интерфейс
- netlify/functions/steam-price.js — Netlify Function
- netlify.toml — настройки Netlify Functions
- test-results.json — зафиксированный пример реального ответа тестового запуска; не используется сайтом как источник данных

Архив готов для загрузки в отдельный Netlify site.

Обновление v2: запросы тестов выполняются последовательно, а курс ЦБ кэшируется на 10 минут и запрашивается с повторными попытками. Это снижает вероятность кратковременного fetch failed при одновременных вызовах.
