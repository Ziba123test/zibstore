ZibStore v112 — внутренние варианты изданий Digiseller как виртуальные товары

Что изменилось
1. Товар Digiseller с внутренним параметром «Выбор издания» больше не обязан
   отображаться одной общей карточкой.
2. Доступные варианты издания превращаются только внутри ЗибСтора в
   виртуальные предложения. Реальных товаров в Digiseller не создаётся.
3. Пример Resident Evil Requiem:
   - один Product ID с Standard/Deluxe ключом -> две виртуальные карточки;
   - каждая карточка может объединиться с соответствующим отдельным Gift
     через уже существующую группировку «Ключ / Гифт».
4. Недоступные варианты (is_available=0) на витрине не показываются.
5. Steam-сопоставления для виртуальных изданий хранятся отдельными ключами
   вида v_PRODUCT_OPTION_VARIANT, поэтому Standard и Deluxe могут иметь разные
   AppID/Package и разные Steam-цены.
6. При покупке виртуального варианта API создаёт свежий Digiseller id_po с
   реальным IP посетителя и отправляет выбранный variant_id в оплату.
7. Обычные товары без внутреннего выбора издания продолжают работать по
   старой логике.

Изменённые рабочие файлы:
- index.html
- api/server.js
